# Mom's Bakery — Rajahmundry
Responsive animated React + Vite single-page bakery website.

## Run it
1. Extract the ZIP and open the folder in VS Code.
2. Open a terminal in the project folder.
3. Run `npm install`
4. Run `npm run assets:download` to download the food photos into `public/images/` (internet required).
5. Run `npm run dev` and open the local URL shown in the terminal.

Production: `npm run build` then `npm run preview`.

Edit page content in `src/App.jsx`, styles in `src/App.css`, and images in `public/images/`. Product categories are illustrative; confirm exact items, prices and availability with the bakery before publishing.
